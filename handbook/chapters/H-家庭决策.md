# 第八章（H）家庭决策：把分数、孩子和家庭放在一起想

> 本章回答："同样的分数，为什么不同家庭该填得不一样？家长在这件事里该做什么、不该做什么？"
> 素材来自笔记 01～19 中与家庭资源、地域、性别、心态、信息辨别有关的内容。涉及收入、薪资、学费的数字都是讲者口述，**只用来说明量级**。讲者对性别、地域的个别说法带有个人色彩，本章只保留与招生、招聘规则直接相关的部分。

---

## 一、先找到家庭的"锚点"
- 讲者："**志愿填报核心四个字：因人而异。**"同样 620 分，不同家庭的最优解可以完全不同。
- 填志愿前，全家先回答一个问题：**我们最看重什么？**

| 锚点 | 典型选择 | 要接受的代价 |
|---|---|---|
| **学校名头（体面）** | 冲 985/211/双一流层次，专业服从 | 可能读不喜欢的专业；大类分流压力 |
| **稳定就业** | 行业院校、国企对口专业（电网、铁路、审计、医学、师范） | 地点可能偏；上限不高 |
| **保研、升学** | 保研率高的快班、强基、"过桥型"学校 | 大学四年要拼绩点 |
| **出国** | 中外合作、港校、港中深、西浦 | 费用高；回国进体制越来越难 |
| **城市** | 南京本地、苏州、上海、杭州 | 同分可能要降学校或专业 |
| **收入上限** | 计算机、电子、金融（高层次学校） | 竞争激烈、行业波动 |

- 锚点可以不止一个，但要**排出先后**。讲者的很多建议都是"先定锚点，再排除缺点"："高考志愿是靠排除缺点做出来的，不是比优点。"

---

## 二、盘点家庭的"超能力"
讲者把家庭条件叫作"超能力"：它会直接改变填法。

| 资源 | 会改变什么（讲者举例） |
|---|---|
| **经济条件** | 能否用中外合作"花钱买分"守住院校层次；能否选港中深、港校、华工国际校区；普通批有中外合作兜底时，综评可以不服从调剂 |
| **行业资源（医疗）** | 家里资源在哪家医院，决定南大医学院还是南医大；有医疗资源时南医大临床性价比更高 |
| **行业资源（法律、金融、烟草等）** | 法学"先看性格，再看家庭资源"；烟草、部分金融岗位需要社会资源，普通家庭不推荐 |
| **行业资源（电网、航空等）** | 了解行业认可哪些学校（例：家长有航空资源，要求本科双一流 → 选南林自动化而不是航空院校） |
| **户籍与居住地** | 南京、苏州本地人对本地学校的偏好；农村户籍可查专项计划；教师编、警校回生源地 |
| **孩子的性格与天赋** | 外向适合法学；数学难题强适合强基和数学类；动手弱选"动脑"专业；色觉、身高影响特定行业 |
| **孩子的意愿** | "强扭的瓜不甜"：选科和选专业都要孩子愿意 |

## 三、钱：预算决定选项
### 3.1 学费量级（讲者口述，2025 年前后）
| 选项 | 学费 / 总花费 |
|---|---|
| 公办普通专业 | 约 0.5～0.6 万元/年 |
| 省内中外合作（4+0 为主） | 约 2.6～6.6 万元/年（苏大、南师大、南审等） |
| 外省 211/985 中外合作 | 约 4～10 万元/年（地大、西北大学、北航中法、东北秦皇岛等） |
| 华南理工广州国际校区（综评） | 约 9.5 万元/年 |
| 港校 | 拿到 offer 后先交约 2 万元留位费（不退） |
| 港中深 | 本科约 13.5 万元/年；讲者估算"本科 + 海外硕士"约 200 万元，"在能拿出约 300 万元预算的前提下能省 100 万" |
| 出国读本科（如澳大利亚） | 讲者口述本科约 80 万元，加研究生约 150 万元 |

### 3.2 怎么用预算
- **"花钱买分"是合理的**：985 的中外合作最多从"中 9"降到"下 9"，守得住院校层次；越贵的项目分越低。
- **有钱也要算清楚**：华工国际校区约 45% 的人本可以上本部（讲者口述）；港中深读完本科再回国内读研"就是浪费钱"。
- **先填完内地志愿，再决定交不交港校留位费**。
- **不差钱的家庭**：有的学校可以进校后花钱转入中外合作，"相当于没有调剂风险"；普通批有中外合作兜底，综评就能大胆不服从调剂。
- **预算有限的家庭**：优先考虑学费低、4+0、单独成组的中外合作（如苏大新能源、上海大学信息工程），或直接选普通专业。
- 讲者提醒：即使家里条件好，也不要让孩子在大学期间过得太奢侈。

## 四、地域：留在江苏还是出省
- **600 分以下基本不必出省**：理科约 600 分（约 3.5 万名）、文科约 590 分（约 8300 名）以下是省属院校层次，外省省属院校分数不会比本省低。例外：为了 211 名头、特殊专业（医学、铁路、法学）或北京"捡漏"。
- **620～630 分文科基本要出省**：省内 985/211 在这个分段"断档"。
- **985 段讲者更推荐外地 985**：本科和高中一样"都是为了升学"；除非学法学且家里有本地资源。
- **考上 985 的孩子可能去上海、杭州、北京工作**，家长要有心理准备；苏州是上海的产业外溢。
- **本地就业**：南京理工科岗位在江北、江宁、雨花（"千万不要看不起"）；主城区以金融、文旅、商贸为主。
- **地域性专业**：医学、动物医学、农林最好在本地区读（西北农林、东北医学回江苏有难度）。
- **"体面"与务实**：讲者观察南京家长更看重"体面"，苏州更务实（例：机电一体化在苏州录取排名更靠前）。家长可以想一想，自己的选择是为了孩子还是为了面子。

## 五、性别：只看招生和招聘规则里的硬约束
> 这部分只整理与招生、体检、招聘规则相关的客观限制和讲者的观察，**不代表对任何性别的能力判断**。最终应尊重孩子的兴趣。

| 情况 | 讲者口述要点 |
|---|---|
| 警校、民航安防、中国人民警察大学海关缉私等 | 有的只招男生，有身高、视力、色觉要求；**一定读章程** |
| 电网 | 不收色盲色弱（高考不限制，但就业限制）；讲者观察女生进电网 211 背景更重要 |
| 传统工科（机械、电气、能动、机器人、自动化） | 讲者观察：985/211 就业还可以，以下层次女生招聘难度较大 |
| 护理 | 讲者观察：女生就业好，男护士需求集中在急诊、手术室；大医院招聘对身高有隐性偏好 |
| 中国民航大学 | 原则上只招男生，全校不收色盲色弱 |

- **色觉检查要尽早做**：影响电网、警校、部分理工和医学专业。
- 讲者给"求稳女生"的常见建议（仅供参考）：电气（南师大起，考区县供电局）、口腔、财会、地理、偏软件的通信方向。

## 六、孩子：意愿、性格和天赋
- **意愿第一**："强扭的瓜不甜"。折算成绩显示文科更好，但孩子不愿意，就不要强迫。
- **性格决定部分专业的上限**：
  - 法学要外向、能和"三教九流"打交道，"否则家里资源再多也接不住"；
  - 内向的文科生可以考虑考公考编方向（中文、新闻）或"公对公"的专业（如海洋法）；
  - 动手能力弱，选"动脑"的专业（计算机、网安、软件）。
- **天赋要看具体证据**，不看感觉：
  - 数学：难题（一模最后两道大题 + 填空最后一题，共 39 分）能否稳定拿 25 分；
  - 力学："天才学力"；
  - 物理：做浙江卷轻不轻松。
- **"卷不卷"也是选择**：华科、哈工大快班极卷；武大"牌子够大、不那么卷"；不想太卷的高分考生可以选专业任选的学校。
- **让孩子参与**：翻阳光高考网的专业介绍、翻下学期教材（选科时）、看目标学校的培养方案。

## 七、风险偏好：冲、稳、保怎么分配
- **高考比的是下限**：先保证"最差会落到哪里"能接受，再往上冲（第二章）。
- **可以赌的地方只有层次交界处**，而且"**有稳的就不去趟浑水**"（第三章）。
- **冲可以，别太猛**：讲者案例——妈妈想用综评冲南信工，讲者建议冲南林，因为南林最低专业兜得住"双一流"底线。
- **锁档项目要"愿赌服输"**：东大综评、南大强基等一旦锁档，考得再好也要去；报之前全家达成共识。
- **学会"借力"**：用综评、中外合作、强基给普通批做加法或兜底（第四章）；"换批次比换地域有效"。
- **把转专业纳入计划**：985 转专业普遍自由；选课程相关的专业进校再转；但不要把"插班生""转专业"当主要路线。

## 八、信息：怎么辨别听到的建议
| 听到的说法 | 讲者提醒 |
|---|---|
| "身边很多人说某校好" | **要看他们考多少分**。某个分数段的收分，是由那个分数段的家庭决定的 |
| "某专业综评降了 10 分" | 降分数据常是"圈套"（例：东大吴健雄综评），要看入围机制和自己的条件 |
| "某校最高分很高" | 高得离谱的最高分多是准备复读、随便填后被退档的"死档"，不必参考 |
| "某校过一本线人数创新高" | 特控线越划越宽，人数增加不代表成绩提高 |
| "软科排名更高" | 讲者认为排名参考价值有限 |
| "学法学考公更容易""学医一定要选生物" | 都是常见误解（第六、七章） |
| 讲座、宣传片 | 不要只听了讲座就"走不动道"，要同分比较其他学校 |
| 付费规划师 | 讲者称有的规划师"只填小组、文科留 10 分"，客观上抬高了某些专业分数；**家长要理解填报逻辑，而不是只要一张表** |
| 机构内部数据 | 相关系数、录取分布等常是内部统计，样本不公开，只作参考 |

- **信息源的优先级**：教育考试院和阳光高考网的官方文件 > 学校招生章程和官网 > 往年真实录取数据 > 他人经验。
- **章程一定要读**：体检、身高、单科成绩、是否包分配（如消防救援学院、上海海关学院写明"不包分配"）都写在章程里。

## 九、时间与分工：全家怎么配合
### 9.1 高三全年
| 时间 | 家长要做的事 |
|---|---|
| 高三上（9 月零模、1 月期末） | 记录每次考试的市排名、本校同组合百分比；期末不是最接近高考的一次，"考好了别松懈，考差了别气馁" |
| 3 月一模 | 建立定位区间（第二章）；弄清普通批能上什么；筛选强基 |
| 4 月 | 强基报名（约 4/25 截止）；关注综评章程 |
| 5 月 | 综评报名（约 5/1～5/10，学校盖章时间很短）；约 5/31 综评 A 填志愿、B 类确认；**5 月是孩子最疲惫的阶段** |
| 6 月 | 高考、校测；出分（约 6/24）后 A 类确认、南大兴趣类校测 |
| 约 6/28～7/2 | 填报志愿；港校面试 |

### 9.2 考试当天和出分后
- **考试期间**：孩子说考砸了就安慰，考好了提醒冷静，引导注意力到后面的强项科目；家长要有"底线思维"。
- **校考当天**：建议坐公共交通，或把孩子送到附近再去找车位。
- **填报期间**：
  - 志愿在截止时间（讲者举例 7 月 2 日 17:00）前可以随意修改，以截止时的版本为准；
  - 和学校"谈专业"时，有的学校要求截图证明前面没填竞争学校，截图后仍可改回（讲者口述，以当年规则为准）；
  - **警校、提前批、综评、普通批一次填完**；填完警校后心态上要当作"警校没录"，认真填好后面的志愿。
- **全家分工建议**：一人负责数据（一分一段表、往年专业组分数），一人负责读章程和培养方案，孩子负责表达偏好；最后一起按"从下往上"的顺序定表。

## 十、考砸了怎么办
- **先判断是"不会做"还是"没发挥"**：问孩子"会不会做"，不要问"考得好不好"。
- **保住层次的几条路**：
  - 综评 B 类：挑最差的六个专业、服从调剂，保本科或保一本层次（第四章）；
  - 用中外合作守住院校层次；
  - 行业院校、特色专业（如南林轻化工程、江科大船舶）先解决就业；
  - 征集志愿：讲者早年用征集志愿把一名化学极强的学生填进有色金属冶炼，后来直博。
- **复读要想清楚**：可以考虑调整选科（讲者案例：复读时把历史换成物理，总分超过本科线 30 多分），但复读的心理成本和政策变化都要评估。
- **心态**：讲者说一般不用往下看 50 分，除非考试中心态崩溃；家长在考试期间的稳定比任何技巧都重要。

## 十一、家庭决策流程（一页纸版）
1. **定锚点**：全家排出"名头 / 就业 / 升学 / 出国 / 城市 / 收入"的先后。
2. **盘资源**：预算上限、行业资源、户籍、孩子性格天赋、孩子意愿。
3. **定区间**：用多次考试折算出"往上 20、往下 15"（文科 15/10）的位次区间。
4. **定普通批**：按专业组，从下往上排出保、稳、冲（第三章）。
5. **做加法**：决定强基、综评、中外合作、港校、提前批要不要报、报哪个（第四章）。
6. **排除缺点**：对每个候选逐一问"最坏情况能不能接受"。
7. **全家确认**：锁档项目、服不服从调剂、要不要出省，出分前达成共识。
8. **按时提交**：列好日期表，截止前反复核对。

## 十二、家长自查清单
- [ ] 全家对"最看重什么"达成一致了吗？
- [ ] 我清楚家里的预算上限，并据此划掉了负担不起的选项吗？
- [ ] 我读过目标学校的**招生章程**（体检、身高、单科、是否包分配）吗？
- [ ] 孩子做过色觉检查吗？
- [ ] 孩子本人愿意去这些学校、读这些专业吗？
- [ ] 我听到的建议，来自什么分数段、什么家庭？
- [ ] 对锁档项目和不服从调剂的风险，全家都能接受吗？
- [ ] 考砸时的备选方案（综评 B、中外合作、征集志愿）想好了吗？
- [ ] 所有关键日期都记在日历上了吗？
