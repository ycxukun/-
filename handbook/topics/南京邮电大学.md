# 南京邮电大学：全方位档案

> 本专题把 19 场直播中所有涉及**南京邮电大学（南邮）**的内容汇总到一起：定位、专业组、各专业分数、学院设置、贝尔英才班、就业、同分比较、中外合作、综合评价和案例。
> 素材来自笔记 01～19 及直播原文。分数、位次、保研率都是讲者口述（多为 2025 年江苏数据），**填报时必须以当年官方数据和南邮招生章程为准**。

---

## 一、一句话定位
- **双一流（非 211），电子信息类"行业强校"**，讲者称它是 **"610～620 分段打天下的学校"**。
  - 2025 年 610～620 分约 7000 人，南邮在这个分段招约 2215 人，"统治"了这个分段。
  - 讲者："这个分数段基本上就是南邮拳打北海敬老院，脚踏南山幼儿园。"
- **优点**：专业组"干净漂亮"（大组里几乎全是好专业）、在江苏认可度高、华为等企业把它列为"可招"。
- **短板**：
  - 不是 211。讲者提醒："如果四年、六年之后大厂不认南邮了怎么办？苏大是 211，它肯定认。"
  - 在大厂招聘名单里，南邮属于层次较低的学校之一，**南邮的学历能让你进大厂面试，后面要靠能力说话**。
- **适合的人**：愿意吃苦、做电子信息类工作的。讲者："只要愿意当'工具人'、愿意吃苦，没有资源背景也没问题。""新工科就业不挑男女，挑你愿不愿意做牛马。"

## 二、学院设置：看懂南邮的关键
- 南邮的电子信息类学院分得清楚：**通信学院、电子科学（电子工程）学院、集成电路学院、计算机学院**等分开设置（讲者认为这是实力强的学校的分法，和东南类似）。
- **各学院讲者评价**：
  | 学院 | 讲者要点 |
  |---|---|
  | 通信学院 | 王牌：通信工程、电子信息工程、广播电视工程 |
  | 电子学院（电子科学与工程） | 光电、电磁场；光电 2025 年保研率升到约 17% |
  | 柔性电子学院 | 柔性屏、柔性电池、智能穿戴、太阳能帆板；**2025 届保研率约 30%（30.67%）**，在双一流里"独树一帜"；化学好的学起来不难 |
  | 物联网学院 | **"大杂烩"学院**：物联网工程、测控、测绘工程、地理信息、网络工程等"不知道放哪的专业"都放这里；讲者不推荐偏软件的专业，但这里的地理信息"直接教你计算机"，就业反而好 |
  | 现代邮政学院（仙林） | 物流管理（+ 人工智能双学士）、邮政工程 |
  | 经管学院（三牌楼） | 信管双学士等，讲者不推荐 |
  | 设计学院 | 数字媒体技术：培养方案和艺术类数字媒体艺术一样 |
  | 人工智能 | 脱胎于自动化学院，偏自动化方向 |
- **学科评估的"门道"**：南邮的电子科学与技术学科评估是用材料/固体物理方向去评的，讲者说对南邮评上双一流贡献最大的是柔性电子、电子科学中的材料方向。**学科评估不能直接等同于某个本科专业的强弱**。

## 三、招生政策与专业组（手册章节 C）
- **物理 + 化学的大组（07 组，约 20 个专业）**：投档线约 610（约 2.6 万名）。
  - **一进组就出不来**：只想学通信的，这个组整组都不能填，因为你真正要接受的是组里的中档专业（讲者用它讲"看中档专业，不看王牌专业"）。
  - 优点：大组但"里面全是好专业"，**不用留分**（讲者对比福州大学：福大微电子同分但专业组杂，要留约 3 分）。
- **物理 + 不限组**：物流管理 + 人工智能双学士（约 608）等。
- **分数变化**：2023 年理工科还没大扩招，南邮普通批约 2 万名；现在约 2.6 万名。杭电 2024 年分数比南邮高，讲者说"明显不正常"。
- **本省学校对江苏考生是"好"的**：讲者引用外省规划师的话，南邮在外省的分数"动不动就干到某个顶二的水平"，所以相对而言对江苏考生很友好。

## 四、各专业分数（2025 年，讲者口述）
### 4.1 理科（物理类）
| 专业 | 分数（位次） | 讲者要点 |
|---|---|---|
| 贝尔英才班（电子信息类，含人工智能与中科院南京所联培） | 约 637（9279 名） | 见第五节 |
| 通信工程 | 约 622～623 | 全校普通专业最高；约 620 分能上通信学院 |
| 电子信息工程 | 约 616 | 通信学院；讲者说它≈"通信工程 + 强化计算机"，和通信"没有本质区别" |
| 电子科学与技术 | 约 616～621 | 讲者认为"报了有点亏"（省内 620～630 分段唯一的"疏漏"） |
| 微电子 | 约 618 | 南邮是全国 25 所示范性微电子学院之一，和福州大学同分 |
| 柔性电子学 | 约 610～612 | 保研约 30%，讲者多次重点推荐 |
| 光电、电磁场（电子学院） | 约 610 | 光电保研约 17% |
| 物联网工程、网络工程（物联网学院） | 约 610 | "610 分整" |
| 07 组投档线 | 约 610 | — |
| 物流管理 + 人工智能双学士（现代邮政学院） | 约 608 | 京东、顺丰、阿里的实验室在南邮，也来南邮校招；讲者称"双学士有点假，但不妨碍校招" |
| 数字媒体技术（地方专项） | 约 606 | 在设计学院，普通批不招 |

- **"590 分想学本省新工科"**：讲者说只有南邮（物联网、电磁场、光电、网络工程、柔性电子）。
- **约 620 分想学电子、自动化**：讲者说"有南邮在面前"，除了通信工程其他都够。
- **约 590 分想学硬件**（半导体物理、有机光电、材料化学）选南邮综评；学软件选南信工。

### 4.2 文科（历史类）
| 专业 | 分数 | 讲者要点 |
|---|---|---|
| 物流管理 | 约 587～592 | 学用软件调度供应链（从下单到快递送达）；文科单独成班，内容和理科基本一样，理科双学士多一些 AI、自动化课程；讲者强调它**不是文理兼招专业** |
| 财务管理 | 约 588～590 | 587 分不够 |

## 五、贝尔英才班：值不值得报
- 2025 年最低约 637 分（9279 名）；讲者说实际保研率约 40%。
- **讲者的判断：对大多数人"没有价值"**。
  - 这个分数可以上武汉理工通信本硕班、天大等 985、华南理工综评等；
  - 毕业证仍是南邮（双一流），不是 211/985。
- **只有一种人适合**：数学、物理或信息学竞赛有特长（如省一），打算"用南邮学历进大厂面试，再靠能力和奖项说话"的。
- 讲者另一场也说过贝尔"好的不得了"，但前提仍是"你看不看得上这个分数能上的其他学校"。
- **贝尔英才 vs 河海大组**（分数相近）：看孩子想要"高投入高回报"（电子、互联网，996）还是"中等收入、稳定"（水利、电网，朝九晚五）。

## 六、就业与行业
- **软件与信息服务**：南京雨花软件谷的大厂招聘看学校层次，南邮是进入名单中层次较低的之一；从基础工作做起，除非能力突出（例：有国家级竞赛奖）。
- 讲者建议：想学软件"最好 211 往上"；分数够 211、985 的就不一定报南邮。
- **计算机专业**：讲者一般只推荐 985/211 的计算机，**外加南邮、杭电**。
- **女生**：物理弱的女生想读工科，讲者建议选偏软件方向，"那就是南邮那一套"；柔性电子"女生也可以学"。
- **地理信息**：南邮的地信属于物联网学院，偏计算机（Python、C++、Java），讲者说"南邮选择了弯道超车，用计算机搞地信"，就业好。
- 南邮通信 vs 电子信息工程：通信学理论更多，电子信息工程加强计算机，"一个 616，一个 622，没有本质区别"。

## 七、综合评价（B 类，手册章节 D）
### 7.1 综评招什么
- **强物理的专业只在综评招、普通批不招**（讲者多次强调）：
  | 专业 | 讲者要点 |
  |---|---|
  | 材料物理（讲者说现已改名"电子信息材料"） | 依托有机电子相关国家重点实验室，方向是柔性屏、光纤传输、智能穿戴；约 580 分段 |
  | 材料化学（讲者说现已改名"新能源材料与器件"） | 同上；两个专业分在物理学院和化学生命科学学院 |
  | 广播电视工程 | 通信学院最后一个专业，学信号与信号转换，研究生对应"信号与信息处理"，"和通信学的几乎一样，还跳过了一些很难的课"；讲者说 2025 年全省最低分是他服务的一位苏州学生 |
  | 邮政工程 | 只在综评招；2025 年中位数约 605、最低约 599；和文科物流管理基本同一套课程 |
  | 地理信息科学 | 物联网学院；讲者举例 580 分走综评录取 |
  | 生物医学工程 | 580 分段可冲 |
  | 金融类（金融科技） | 2025 年南邮综评最低录取是金融科技 572 |
- **热门专业不降分**：讲者："南邮热门专业，你指望它降分？别指望了。"通信也不降分，而且招得少。
- 历史：2023 年南邮综评改革前最低曾到 517 分（同年普通批 613）。

### 7.2 竞争与报名
- **文科很宽松**：南邮文科最后去面试的只有 100 人出头，招约 35 人。
- **理科竞争困难**。
- 往年很多名校学生报了南邮综评，最后并不去面试（讲者说常有家长交了培训费又退费）。
- **2026 年趋势**：综评 B 类放宽成绩通道，讲者认为最受益的是"以前报不了名的中档学校的中档考生"。
- **和南信工同一天校测**（例：南邮 6/14 上午、南信工 6/14 下午），**按天算冲突，只能确认一所**。
- **和南师大**：211 段考生多确认南师大；想学电子信息的选南邮。
- 申请很简单（讲者说"几分钟"），纠结超过半小时就先申了再说；5/31 再决定确认哪所。

### 7.3 面试
- **文理分卷，考学科应用**；形式每年不同：2023 年自我介绍 + 两道必答题；2024 年两道必答题；2025 年屏幕三选二。
- 理科：一般两道自然素养题（**偏物理**）+ 一道人文素养题；文科：基本是经济类题目。
- 难度：文科简单，理科"有难度，但不叫很难"。
- 押题有一定价值：南邮某年考了上海大学 2023 年综评原题（稍加改动）。
- 奖项在面试中没用，考官看不到资料。

### 7.4 怎么用
- **冲**：
  - 616 分（普通批能上电子信息工程）→ 综评填通信工程（冲）+ 电子信息工程（双报），不服从调剂；
  - 612 分（普通批能上光电）→ 综评填通信、电子科学与技术、广播电视工程；
  - 约 620 分想进通信学院 → 普通批冲通信，综评把广播电视工程放在下面兜底；
  - 讲者例：折算分超过 620，可以在综评里"通信工程 + 普通批能上的专业"双报。
- **保（保住"南邮"）**：
  - 折算约 580 分（普通批只能上江科大等）→ 综评报地理信息、生物医学工程、材料物理，讲者认为"学校层次完全不一样"；
  - 折算约 610～632 分的，讲者也把"南林、南邮综评"列为兜底；
  - 讲者：强物理专业综评约 580 分，高分考生去读"浪费分太多"，只作保底。
- **选校**：综评 B 选校表里，折算理科 ≥590 / 文科 ≥580 的，讲者建议"南邮、南信工、南林（+ 南师大）全申"；文科加南邮分低一点但专业会差一点；想上"南邮金融"这类特色专业的可以搭配申请。

## 八、同分比较（讲者观点）
| 比较 | 讲者观点 |
|---|---|
| 南邮 vs 杭电 | 江苏考生选南邮：杭电好专业留给浙江，物化组 11 个专业只招 37 人、有材料统计等；南邮组里全是好专业 |
| 南邮 vs 浙工 | 想在江苏发展选南邮，想在浙江发展选浙工 |
| 南邮 vs 合工大 | 合工大分数已经把南邮甩开；合工大宣城软工（618，计算机 B+）讲者认为"肯定比南邮要好"，毕业证不写宣城 |
| 南邮 vs 苏大（计算机） | 苏大计算机学院（约 635）211 + NLP 特长，讲者认为"更均衡"；苏大通信则不如南邮 |
| 南邮通信 vs 矿大机器人（都约 622） | 软件"动脑"选南邮，硬件"动手"选矿大 |
| 南邮通信 vs 东华钱宝钧（都约 622） | 讲者用来提醒家长：同分还有上海 211 专业任选的选择 |
| 南邮微电子 vs 福州大学微电子（都约 618） | 要 211 名头选福州（留约 3 分）；要本地、要稳选南邮 |
| 南邮 vs 西安邮电 / 重庆邮电 | 有南邮的分不报西邮；讲者推荐重邮（"我为这句话负责"） |
| 南邮 vs 西南交通 | 讲者称西南交通是"成都的南邮"，多一个 211 头衔 |
| 南邮 vs 江南大学物联网学院（621） | 讲者看好江南的前景，但当下在南京就业更看好南邮 |
| 南邮 vs 南信工 | 南信工统治 600～610，南邮统治 610～620；590 分硬件选南邮、软件选南信工 |
| 南邮 vs 华中农业计算机等"边缘 211" | 2.6 万名附近，讲者认为有些 211"还不如南邮" |

## 九、中外合作
- 与美国波特兰州立大学的合作 2025 年结束。
- 2026 年起改为与**塞浦路斯某大学**合作，专业为**数据科学、生物医学工程**，首年、没有数据；讲者说"外方不是什么好学校，当普通专业看"；608 分不推荐，但**590～600 分想留南京读新工科，可以把它放在前面"拼一枪"**；"如果你要南邮的牌子就报，其他情况不推荐"。
- 讲者提醒：中外合作的"升学率"好看，是因为考不上国内研究生的可以花钱出国读研。

## 十、案例（讲者口述，已匿名）
1. **地方专项的教训**：一名考生 612 分，通过地方专项录了南邮数字媒体技术（地方专项 606，在设计学院，学的是艺术类数字媒体艺术的课）。讲者说如果按"普通批 → 多元录取 → 提前批"的顺序想，他普通批就能上南邮柔性电子、光电、电磁场、物联网。
2. **580 分进南邮**：一名考生综评以约 580 分录取南邮地理信息（物联网学院，学计算机三门语言），"580 分你上什么学校的计算机？"——讲者用这个例子说明综评"专业不好"是倒果为因。
3. **不挑专业只要 211**：一名 587 分的考生想上 211，讲者说"587 分连南邮财务管理都不够"，最后花钱上了西南财经中外合作。
