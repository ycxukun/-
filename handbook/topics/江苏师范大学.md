# 江苏师范大学：全方位档案

> 本专题把 19 场直播中所有涉及**江苏师范大学（江苏师大）**的内容汇总到一起：定位、分数、电气/计算机/机械/人工智能、文科专业、地理信息、2025 年收分下滑、中外合作、综合评价和同分比较。
> 素材来自笔记 01～19 及直播原文。分数、位次都是讲者口述（多为 2025 年江苏数据），**以江苏师大当年招生章程为准**。讲者对个别专业有情绪化评价，本文只保留他的结论和理由。

---

## 一、一句话定位
- **讲者口中的"苏北唯一的一本"**，"集苏北之力"在建设，"学术能力还是不错的，只不过名字叫师范"。
- **一二本分界的"路灯"**：新高考没有一本线，讲者建议用**南京工程学院或江苏师大**当省内一本的参照物（全国范围的参照物是哈尔滨商业大学）。
- **与同分段学校的分工**：
  - **江苏科技大学张家港校区 = 地域**（在苏州）；
  - **江苏师大 = 学术**（在徐州，有硕士点、实力更强）。
  - 讲者："两种完全不同的选择，你可以来选。"
- **缺点**：在徐州，地域一般；部分新专业（智能交互设计、人工智能、地理信息）讲者认为教学资源一般。

## 二、分数总览（2025 年，讲者口述）
- **最低收分：理科约 532，文科约 562**。讲者用来说明"普通一本段文科比理科凭空多 30 分；理科挑专业最多再花 5 分，文科挑专业要再花 20 分"。
- **2025 年收分大幅下滑**（讲者称"崩盘"），见第五节。
- **理科各专业**：

| 专业 | 分数（位次） | 讲者要点 |
|---|---|---|
| 计算机 | 约 561 | 实力可以 |
| 智能科学 | 约 558 | — |
| **电气** | **约 558（约 8.2 万名）** | 有硕士点；省内一本里想读电气分数最低的选择之一 |
| 电子信息 | 约 557 | — |
| 软件工程 | 约 552 | — |
| 人工智能 | 约 545 | 和计算机同堂上课 |
| 光电 | 约 541 | — |
| 机械 | — | "学术能力更强"；进徐工比较容易 |

- **文科**：法学院、会计、历史师范、哲学等（部分专业 2025 年低于 570，讲者说"这个分数就不报了"）。

## 三、理科专业怎么选（手册章节 F）
### 3.1 电气：讲者在江苏师大里的首选
- **"如果在江苏师大里选，我会选电气，不选计算机"**：
  - 电气能乘上新能源、AI 的风；计算机的普通程序员岗位更容易被 AI 替代；
  - 讲者说江苏师大电气的专业实力比计算机稍强。
- **省内电气的"断档"**：约 580 分想学电气，省内一本电气分数最低的两家是江科大（约 582）和江苏师大（约 558），中间基本断档（南通大学约 583，讲者说实力一般）。讲者：约 578 分的女生想读工科，"电气省内就只有江苏师大了"。
- 讲者说江苏师大电气**有硕士点**（他说南林电气没有），在普通一本里算强，但徐州地域不好。
- **电气 vs 机械**：电气起薪高；后期能否持续比机械高，要看"动手能力强、勤学好问"；普通一本的电气和机械都常要出差、调试。

### 3.2 机械：纯就业可以进徐工
- 讲者把"江苏师大机械进徐工"列为约 564 分**纯就业**路线之一（另两条是大连交通材料成型、南京工程学院能源动力）。
- **不要报"智能交互设计"**（机械学院）：讲者说这个专业"很难教明白"，学正统机械更好，"江苏师大的机械还真的不错"。

### 3.3 计算机与人工智能
- 计算机约 561，实力可以。
- **人工智能**约 545，讲者说"江苏师大教的其实就是计算机，一个课堂上一半是人工智能专业、一半是计算机"。
- 综评想"纠结专业"的，讲者说可以报江苏师大人工智能（算热门专业）。

### 3.4 地理信息：两种说法
- **理科**：讲者说江苏师大地理信息在**测绘学院**，偏实地测绘，不是数字测绘、定位、地图这类"地理信息系统"，好学校和差学校两极分化。
- **文科（文转理）**：想学地理信息的文科生，省内有三所学校在文科招地理方向且入学后能分流到地理信息——**苏州科技大学（讲者最推荐）、江苏师大、江苏海洋大学**；南师大文科生"几乎分不过去"。

## 四、文科专业
- **法学**：
  - 文科约 590 分只想学法学的，讲者说"常州大学史良法学院或江苏师大法学院做保底"；
  - 文科约 572 分想学法学，江苏师大法学院、常州大学史良法学院、南工大法政学院（综评）都是"很好的选择"（讲者对南通法学、南林法学评价低，因为分别在历史文化学院、马克思主义学院）。
- **会计**：文科约 579 分学会计，同层次剩常州大学、江苏师大，讲者更推荐南审中外合作（要出国一年，约 579 / 11880 名）。
- **经管**：物化地约 550 分（折算约 553，约 8.9 万名）的女生想学经管，讲者说"去苏北，江苏师大专业都够，全都能选"。
- **文科约 545（折算约 572，约 1.45 万名）**：省内一本可选常州大学（史良法学院、秋白政府管理学院、吴敬琏经济学院）、苏州科技大学财务管理；"质量跟常州大学相当的是江苏师大，但选择面比较小"。
- **师范**：
  - 讲者提醒：南京考教师编，**以本科身份报考必须是师范专业**，研究生身份不限；
  - 文科约 523 分（约 2.46 万名）的考生，讲者建议综评冲江苏师大师范，"不要管师范好不好，学校档次拉高太多"；
  - **数学师范要看学科特点**：讲者举例一名数学 90 分的考生报了江苏师大数学师范，"强扭的瓜不甜"，数学弱应该报语文、英语师范。

## 五、2025 年收分下滑：一个关于"冲"的教训（手册章节 C）
- 讲者说江苏师大 **2025 年收分"遇到了大的滑坡"**。
- **案例**：一名考生照搬 2022～2024 年的分数，从第一个专业志愿就开始"稳"，填了智能交互设计。结果当年分数崩了，前面没冲，本可以录更好的专业。
- **讲者的结论**：**六个专业志愿"冲 2、稳 2、保 2"**。学校收分崩盘时，只有冲的志愿才能吃到红利。"我不要求家长能预判哪个学校会崩，但你要会用这个方法。"

## 六、中外合作
- 讲者提到江苏师大有中外合作办学项目，但讲得很少。
- 对比深北莫：一名分数只有约 540～550 的考生，讲者说走综评 A 类深北莫，"只要跟无锡学院、一本的中外合作（常州大学、江苏师大）比，比他们强就是强"。

## 七、同分比较（讲者观点）
| 比较 | 讲者观点 |
|---|---|
| 江苏师大 vs 江科大张家港 | 江苏师大偏学术，张家港偏地域，按需求选 |
| 江苏师大 vs 济南大学、浙江科技大学（约 560～568） | 分数够时讲者更推荐省外这两所（济南大学有院士，浙江科技在杭州/湖州） |
| 江苏师大电气 vs 湖南工业大学电气（株洲） | 讲者说湖南工业大学电气实力更强，可进中车株机，卓越班保研约 15%，但只招两三个人 |
| 江苏师大 vs 金陵科技学院（约 551～553） | 分数在约 551 时讲者说"千万不要报苏南学校"，报江苏师大 |
| 江苏师大 vs 广东外语外贸（理科约 554～560） | 讲者说广外更好（能录经济统计、金融、财管，保研约 5%） |
| 江苏师大 vs 南京林业大学（电气、计算机、机械） | 讲者说江苏师大这三个专业实力更强（口述） |
| 江苏师大法学院 vs 常州大学史良法学院 | 都可以做法学保底 |
| 江苏师大地信 vs 苏州科技地信（文科） | 讲者最推荐苏州科技 |
| 江苏师大会计 vs 南审中外合作会计（文科约 579） | 选南审中外合作 |

## 八、综合评价（B 类，手册章节 D）
### 8.1 流程与面试（讲者口述）
- **报名截止早**：江苏师大、南林往年约 **5/9～5/10** 就截止申请，比其他学校早，要先申请再挑学校。
- **面试不分文理**；讲者说大多数 B 类是"走进考场看屏幕答题"，而**扬大、西交利物浦、江苏师大**三所是例外（具体形式讲者未展开，以简章为准）。
- **个人陈述要提交**（讲者说多数学校基本不看）。
- 讲者提到江苏师大的确认截止时间是各校中最晚的之一（具体日期转写不清，以简章为准）。

### 8.2 怎么用
- **选校表**（按折算成绩）：
  - **理科约 560～590 / 文科约 570～580**："一本全申"——南工大、江苏师大、江苏大学、扬大，再搭配自己喜欢的双一流；"真不放心再加江苏师大"；
  - **理科低于约 560 / 文科低于约 570**：南工大、江苏师大、江苏大学、南通、扬大**全申**；**想要专业就选江苏师大（人工智能）+ 南通**。
- **讲者的偏好**：综评 B 类他不太推荐扬大（招生计划校考后才公布、普通批常不降分），**更推荐南通大学或江苏师大**。
- **"一定要选"**：分数不够时，讲者说"江苏师大的工科专业一定要选，再不上江苏师大，要么去外省（鲁东、云南师范、西北师范、湖南工业、福建农林、江西农业、哈尔滨商业等），要么真得去二本"。
- **文科低分**：文科约 523 分的考生，综评可冲江苏师大师范或南通大学学前教育（进校再转专业）。

## 九、案例（讲者口述，已匿名）
1. **照搬往年分数，错过更好的专业**：见第五节，考生从第一个专业就开始"稳"，填了智能交互设计，而当年江苏师大分数大幅下滑。
2. **数学 90 分报数学师范**：讲者提醒要按学科特点选专业。
