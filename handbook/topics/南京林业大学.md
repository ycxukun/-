# 南京林业大学：全方位档案

> 本专题把 19 场直播中所有涉及**南京林业大学（南林）**的内容汇总到一起：定位、为什么这么热门、校区与专业组、各专业分数、真正好的专业、热门专业的"真相"、文科、中外合作、综合评价和案例。
> 素材来自笔记 01～19 及直播原文（转写中常把"南林"写成"南宁"）。分数、位次都是讲者口述（多为 2025 年江苏数据），**填报时必须以当年官方数据和南林招生章程为准**。讲者对南林个别专业的评价语气较重，本文已尽量中性化。

---

## 一、一句话定位
- **"南京最热门的学校，没有之一"**：2025 年南京考生录取人数在 560～570、570～580、580～590、590～600 四个十分段**连续排第一**。
- **为什么这么热**：它是**双一流**，而且**分数几乎是全国双一流最低**（文科只有天津中医药、西南石油比它低；理科全国最低）。"6 万多名就能上双一流。"
- **讲者的核心判断**：
  - "**硬币的正面是双一流，反面是热门专业实力非常一般。**"
  - "**冲南林的热门专业，就是冲'双一流'三个字**。觉得双一流重要就报，不重要就别报。"
  - 真正的好专业是**特色专业**：轻化工程（造纸）、化学工程、林业工程、风景园林、城乡规划等。
- **适合的人**：高考约 6.5 万名左右、渴望稳定就业的考生；或者家里把"双一流"当红线的考生。
- 讲者提醒："**身边很多人说南林好，要看他们考多少分**。"585 分以上能选南工大、江苏大学好专业的，别从众。
- 讲者引用的例子：有一位行业内的领导也要求孩子必须上双一流，最后孩子上了南林。"在中国，双一流、211 是金字招牌。"

---

## 二、校区与培养模式
- **都是"2+2"**：
  - **南京校区**：前两年在溧水（离新庄本部约 80 公里），后两年回新庄；
  - **淮安校区**：前两年在淮安（约 180 公里），后两年回南京新庄。
- 淮安校区分数更低；讲者提醒淮安前两年"平时看不到老师，老师一坐大巴车都回南京了"。

---

## 三、招生政策与专业组（手册章节 C）
- **小组招生**："南林是小组、南信工是大组"，所以南林报起来放心，热门专业分数反而比南信工高。
- **2025 年全盘重做专业组，结果"收分崩了"**，讲者预计 2026 年可能继续改或改回 2024 年的样子。
- **2025 年断档**：南京校区土木工程（约 527）、交通工程（约 545）所在的组断档；**不要以此为标准**，2024 年最低分约 559 更有参考价值。讲者也把这类"烂组"称为"想实现层次跨越、不挑专业的人的机会"。
- **组内保底专业**：低分组里常有生态修复、生态学、野生动物保护、土地荒漠化防治等专业，讲者说"要不要报自己看着办"。
- **多少分能冲南林**：讲者说省排名约 7.3 万名以内（约 568～569 分）都有机会，7 万名以前比较稳。

### 4.2 文科
- **南林文科不招任何学数学的专业**（包括会计；风景园林属于建筑大类也不在文科招）。讲者对南林文科专业评价很低，"对文科生极其不公平"。
- **法学在马克思主义学院**，没有独立法学院、没有硕博点，很多课从别的学院请人来上，讲者不推荐（同分可选江苏大学法学、常州大学史良法学院、江苏师大法学院、南工大法政学院）。
- 文科分数低、专业差时，讲者说南林淮安、扬大、南通是"给什么是什么，进去再换"。

## 五、热门专业的"真相"（讲者用"学院归属"来说明）
| 专业 | 所在学院 | 讲者要点 |
|---|---|---|
| 法学 | 马克思主义学院 | 见上 |
| 地理信息科学 | 林草学院 | 做测绘，讲者认为较弱（江苏学地信推荐南大、南师大、南信工） |
| 能源与动力工程 | 材料学院 | 方向是大型空调制冷材料和生物质能（"通俗说是烧垃圾、烧木头"） |
| 电气、电子信息、计算机 | 同一个"信息科学技术学院" | 讲者："三个完全不同的热门专业放在一个学院"，电气没有硕士点 |
| 计算机 | 同上 | **2024 年才有学硕点** |
| 机器人工程 | — | 偏园林机械 |
| 人工智能 | — | 讲者说"差"，不便细说 |
| 大数据管理与应用 | 经济管理学院 | 学的基本是会计课，讲者说有学生读到大二还没上过计算机课 |

- 讲者的结论：南林热门专业"分数不低、实力一般"，是"冲双一流三个字"；电网系院校（长沙理工、三峡、东北电力）的电气都比南林强。

## 六、真正好的专业
- **轻化工程（造纸方向）**（食品与轻工学院）：
  - 全国排名第二，第一是东北林业大学；"以长江为界，一南一北"，其他学校的轻化工程多是纺织服装方向，**造纸企业只能来这两所学校招人**；
  - 方向包括造纸、卸妆棉、医用棉、厨房纸等；
  - 淮安校区约 565 分就能上，"几乎包就业"。
- **化学工程学院**：化学工程与工艺；进校后可以二次选拔进**梁溪学院（保研约 30%）**。讲者："你这个分想上南工大化工差一大截，南林不但是双一流，化工还厉害。"
- **林业工程**：双一流学科，A+。
- **风景园林、城乡规划**：学术实力极强（讲者说风景园林大约在北林之后，与东大、清华、同济一档），但**行业不景气**。**城乡规划是五年制**。
- **机械**（机电学院）：讲者说南林机械不如江苏大学、南工大，但"**在双一流里，考本校研究生最容易的就是南林**"，机械行业看重研究生学历；机电学院保研率约 11%（讲者现场查的 11.36%）。机电学院的自动化、机械设计制造及其自动化也可以做保底。
- **林学**：讲者把"南林林学、轻化工程"列为综评里值得冲的特色专业。

## 七、中外合作
- 与**加拿大不列颠哥伦比亚大学（UBC）**合作，在国际教育学院；**学制 5 年，后两年必须出国**，国内学费约 2.6 万/年。
- 讲者对比：浙江农林大学与同一所学校合作同类专业，学费约 2 万且可 4+0，"南林太坑了"。

## 八、同分比较（讲者观点）
| 比较 | 讲者观点 |
|---|---|
| 南林 vs 南信工（600～610 分） | 南林南京校区新工科（604）分数高于南信工，但实力不如；讲者建议**这个分段直接划掉南林** |
| 南林 vs 南信工（综评冲双一流） | 讲者反而建议冲**南林**：南林最低专业兜得住双一流底线，还有转专业机会；南信工兜不住 |
| 南林淮安 vs 上海海洋 | **有南林淮安的分就填上海海洋**（上海海洋约低 3 分，因为组里有水产、海洋、生物，留 3 分避开）；同为双一流，城市好、实习机会多；讲者建议"用上海海洋替代南林淮安" |
| 南林 vs 南工大、江苏大学 | 585 分以上能选南工大、江苏大学好专业的，别从众报南林 |
| 南林 vs 江苏科技、江苏师大 | 约 567 分：要双一流选南林淮安轻化工程；不在乎双一流，江科大（地域）或江苏师大（学术，电气、计算机有硕士点）更好 |
| 南林法学 vs 南信工法学 | 南信工（法政学院）更好；讲者两家都不选，会选浙江工业大学法学 |
| 南林电气 vs 三峡、南工大、江苏大学电气 | 约 599 分想学电气、不在乎双一流：三峡智能电网、南工大电气、江苏大学电气（或农业电气化）都比南林强 |
| 南林 vs 南审、南财（财经） | 财经按"南财 → 南林 → 上海立信"的顺序报 |
| 南林 vs 北林（软科排名） | 讲者说软科上南林排名比北林高，"你信吗"——提醒家长不要看软科排名 |

## 九、综合评价（B 类，手册章节 D）
- **报名**：往年约 5/9～5/10 截止（比其他学校早）；综评 B 选校表里，折算理科 ≥590 / 文科 ≥580，讲者建议"南邮、南信工、南林（+ 南师大）全申"。**南林文科不招学数学的专业，文科一般不考虑南林**。
- **面试**：文理不分卷，两道必答的话题阐述。讲者说"南林综评面试高手比较多"。
- **2026 年可能增加笔试**（传闻），往年有奖项加分，现已取消，具体做法未知。
- **降分**：南林比较热门，"热门专业别指望降 20 多分，降十几分可以指望"。
  - 反例：南林计算机普通批南京校区 606、淮安 597，折算 570 分想靠综评上，等于降 36 分，"不现实"。
  - 讲者："综评里挑你喜欢的特色专业（林学、轻化工程），别指望冲热门专业。"
- **填法示例**：570 分报南林，普通批大概是淮安校区或南京校区农林类，综评同时填化工 + 农林（双报）；不想去淮安就勾服从调剂。
- **冲双一流"底线"用南林**：讲者说南林综评"宽容度高"，最低分的专业（野生动物保护等）也是双一流，进去还有转专业机会。
- 高分考生（如折算 632 分）也可以用"南林、南邮综评"兜底。

## 十、案例（讲者口述，已匿名）
1. **轻化工程解决就业**：讲者一位老邻居的孩子考了 581 分，想报江苏科技船舶（582）差一分，最后报了南林南京校区轻化工程，"解决了这个家庭最关键的就业问题"。
2. **综评冲南林保住双一流**：2023 年一名考生成绩从约 14 万名升到约 4.7 万名，家里要求双一流。讲者没让冲南信工，而是综评冲南林；高考约 4.2 万名，综评录南林自动化（约 4.1 万名，当年普通批约 3.5 万名），普通批用中外合作兜底，综评可以不服从调剂。
   - 为什么没选南林计算机：2023 年南林计算机连学硕点都没有。
3. **土木的教训**：讲者 2018 年劝一名学生别报南林土木、改报仪器，用"君以此兴，必以此亡"提醒家长：一个行业越火，越可能因此衰落。

## 十一、按分数段：什么时候推荐南林
| 分数 / 情况 | 讲者建议 |
|---|---|
| 理科约 565～571，要双一流 | 淮安轻化工程（565）、化学工程与工艺（571）；"几乎包就业" |
| 理科约 567～569 | 讲者说约 7.3 万名以内都有机会冲南林 |
| 理科约 580，不挑专业 | 南林能选很多专业，含南京校区轻化工程 |
| 理科约 590～597，想读机械、自动化 | 南林机械（本校考研容易）；自动化可在南林和南信工之间选 |
| 理科约 594～600，新工科 | 讲者更推荐上海海洋（替代南林淮安）或南信工 |
| 理科约 600～610 | 讲者建议**直接划掉南林** |
| 文科 | 讲者基本不推荐南林；分低时"给什么是什么，进去再换" |
| 财经（约 571～586） | 南林经济、会计（直接报会计，别报大数据管理与应用） |
