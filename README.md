# 好生涯升学认知知识库｜无文件夹上传版

这个版本专门解决“GitHub 网页端不好上传文件夹”的问题。

## 只需要上传两个文件

- `index.html`
- `content.js`

上传到 GitHub 仓库根目录后，开启 GitHub Pages 即可访问。

## 后续怎么改内容

主要修改 `content.js`。

- 改专业：搜索专业名称，例如“计算机科学与技术”，修改对应对象里的 `body`、`summary`、`status` 等字段。
- 改学校：搜索学校名称，例如“南京理工大学”。
- 新增内容：复制同类对象，修改 `id`、`title`、`summary`、`body` 等字段。

## 注意

这个版本比 Jekyll 文件夹版更容易上传，但不如文件夹版适合长期维护。正式长期维护仍建议使用 Jekyll 文件夹版或 GitHub Desktop。
